## Key Points

- **Primary choice:** React + Vite + TypeScript (industry standard, type safety, mature ecosystem, fast HMR, scalable component architecture)
- **Runner-up:** Vue 3 + Vite (cleaner syntax for some teams, smaller bundle)
- **Why not others:** Next.js (requires separate Node deployment), SvelteKit (smaller ecosystem), Blazor (slow initial load, adds third runtime story)
- **Vanilla evaluation:** Correct demo-first call; exposed limits (no type safety, monolithic state, manual polling)
- **Migration path:** Non-breaking; create separate Vite project in `src/expense-api/client/`, build to `wwwroot/app/dist/`, no API or deployment changes

## Rationale

RadiusClaim UI can move from vanilla JS to React when the demo surface becomes a richer product experience. React's ecosystem, type safety, and job market (70%+ market share) make it the best long-term choice without breaking the same-origin hosting model that keeps the platform story clean.
