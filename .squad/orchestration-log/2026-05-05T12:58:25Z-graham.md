## Key Findings

1. **Infrastructure Mismatch:** The blog still references Azure Blob Storage as the state store, but the current codebase uses PostgreSQL Flexible Server. This represents a material drift from code to docs.

2. **Dapr Component Projection:** The blog implies that `rad deploy` automatically configures Dapr components, but the current implementation requires an explicit post-deploy step via `scripts/apply-dapr-components-from-recipes.sh`. This is a critical factual error that would mislead readers.

4. **Public Gateway Access:** Claims about public gateway exposure to `expense-api` are not consistently supported by the app model or deployment manifests. The deterministic path is workload-namespace `kubectl port-forward`.
