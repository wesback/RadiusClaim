### Root Cause Separation
Classified Phase 7 Azure deployment failures into two independent buckets:

1. **Credential Bootstrap Gap (Bucket A)**
   - Missing `rad credential register azure` execution
   - Causes `platform-secrets` component failure (Kubernetes secret `azure-azurecloud-default` not found)
   - Trivial one-liner fix
   - Does not explain statestore or pubsub failures

2. **Recipe Template Delivery (Bucket B)**
   - Affects statestore and pubsub components simultaneously
   - "ARM template error: resource X is not defined" pattern
   - Root likely causes: OCI artifacts unpublished, inaccessible, or parameter-incompatible
   - Orthogonal to credential setup

### Debugging Sequence

- Phase 1: Credential registration (immediate)
- Phase 2: Recipe artifact health (5 min)
- Phase 3: Environment parameters (3 min)
- Phase 4: Local recipe validation (10 min)
- Phase 5: Parameter alignment (5 min)
