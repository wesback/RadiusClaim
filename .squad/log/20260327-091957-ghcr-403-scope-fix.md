# GHCR 403 Scope Error Fix

**Date:** 2026-03-27  
**Agent:** Pete  
**Topic:** GHCR token scope error handling in teardown script

## Summary

Enhanced `scripts/teardown.sh` with robust GHCR 403 error detection and actionable guidance.

## Changes

- Added pre-flight token scope validation before any GHCR deletions
- Per-deletion HTTP status parsing:
  - **403**: Auth failure → display fix command + exit early
  - **404**: Not found → skip silently
  - **Other**: Generic warning
- Removed misleading "may not exist or requires manual removal" message
- Surfaced fix command: `gh auth refresh -s delete:packages,read:packages`

## Files Modified

- `scripts/teardown.sh`
- `.squad/agents/pete/history.md`

## Impact

Users now receive clear, actionable guidance when GHCR token scope is insufficient, eliminating confusion from vague error messages.
